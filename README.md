## MC服务器真正吃的是单核，不是核数

Java版服务端的多核优化一直不好，主线程扛绝大多数逻辑，所以四核3.0GHz的机器跑起来可能比双核5.0GHz更卡。雨云在游戏云页面上给了一组换算：1.18+ 版本的服务端消耗大约是 1.16+ 的两倍、1.12.2 的三倍。这也是为什么低版本小服可以很便宜，高版本模组服一上就烧钱。

性能不够时不会直接报错，而是TPS慢慢往下掉：方块挖了不掉、怪物瞬移、开箱延迟，玩家一般先骂腐竹后弃服。

所以选机的判断顺序应该反过来：**先看版本和玩法，再看主频，最后才是核数和内存。**

## 几个容易被忽略的坑

**动态计费要留余额。** 动态计费的逻辑是低价基础月租加上CPU超额部分的日结费用，CPU使用率基准是20%，低于20%不额外计费。不留意余额，某天服务器会直接停掉。面板服另有一种按天计费模式，适合临时开一阵子。

**NAT机型是共用公网IP。** 便宜档位大多是NAT机，靠端口映射对外服务，端口数量有上限。要独立IP得另外加钱买，独立IP会带上独享的防御。开公益服或者要给玩家用默认25565端口的话，得提前算进预算。

**视距和mod数量要实际调。** 官方给的承载人数是按视距6算的，你把视距拉到10，同配置能带的人数会腰斩。开服后先看TPS，再动视距和实体刷新距离。

**试用和退款政策。** 每款产品可以1元试用一天（部分较贵产品试用价更高），每账号限1次；7天内无理由退款，每账号限3次。买之前先用1元试，比看任何测评都直接。

**2核4G够开吗？**
